# 네 가지 모델 문제 수정 — 2026-09-23

> **이력 문서.** 이 기록은 이전 윈도 기반 모델(`StreamingPose`) 기준이다. 현재 코드는 이벤트 기반 `hand_tracking.stream.EventStream`을 쓰고, 잔차 게이트(`anchor_ray_gate`)와 ray 운동 추정(`anchor_motion_fit`)은 시뮬레이터에서 anchor 정확도를 낮춰 **기본값이 꺼져 있다**. 현재 구조는 `HAND_TRANSFORMER.md`를 참고한다.

`MODEL_REANALYSIS_20260923.md`에서 확인한 네 항목을 수정했다. 신경망 파라미터 수는 1,944,909개로 유지되지만 기하 anchor와 flag의 분포가 바뀌므로 새 실행에서 다시 학습·평가해야 한다.

## 수정 방식

1. **스트리밍 버퍼 소유권** — `StreamingPose.push()`에서 Tensor/NumPy 입력을 내부 device/dtype으로 변환한 뒤 features와 mask를 복사한다. 같은 버퍼 재사용, push 직후 외부 변경이 과거 이력에 영향을 주지 않는다.
2. **부분 보정 정답 지표** — `run_epoch()`가 보정 손실과 동일하게 정답이 유한한 카메라·예측 프레임 수를 집계한다. 완전 정답/부분 정답 혼합, 다른 배치 구분, 다른 프레임 수에서도 올바른 가중 평균을 낸다. 모두 미상일 때만 null이다.
3. **이상치 처리** — 정적 삼각측량에 수직 거리/깊이 잔차 게이트 0.18(약 10°)을 추가했다. 큰 불일치의 점을 유효 anchor로 저장하지 않는다. 운동 추정은 시간 이력을 이용한 Huber IRLS(0.02) 3회와 잔차 0.08 초과 관측 제외/재계산을 사용한다. Gauss–Newton 목적함수 내부에는 hard 잔차 게이트를 적용하지 않아, 관측을 무효화하는 방향으로 loss를 회피하지 못하게 한다.
4. **비동기 촬영** — 평균 촬영 시각을 붙인 3D 점의 외삽 대신, 각 카메라 ray와 입력에 기록된 촬영 시각으로 위치·속도 6변수를 직접 푼다. 카메라별 반복 촬영은 가중치를 나누어 중복 증거로 세지 않는다. 관측 개수·카메라 개수·시간 분산·행렬 조건·최종 잔차 RMS를 검사한다. 최종 RMS가 0.005를 넘으면 운동 모델을 채택하지 않는다.

카메라 설치 오차가 그대로 남았거나 비선형 운동을 하는 경우에는 위치·속도 모델이 과도한 속도를 만들어 오차를 키울 수 있다. 이때 검사된 정적 점의 제한적 외삽 → 최근 점 유지 → 손 평균/원점 순으로 대체한다. **대체 경로에는 비동기 편향이 남을 수 있으며, 모든 이상치나 손 ID 오류를 검출하는 보장은 없다.** 특히 두 ray만으로는 잘못된 교차점을 항상 구분할 수 없다.

계산량 증가를 줄이기 위해 모델 앞단은 이력 전체를 활용하되 실제 필요한 마지막 query의 anchor만 계산한다. 전체 query를 계산한 결과의 마지막 값과 일치하는 회귀 검사를 추가했다.

- 전체 단위 테스트 **44개 통과**: 기존 36개 + 새 회귀 테스트 8개.

- Colab 노트북을 재생성했고 내장 소스 5개가 현재 파일과 일치한다. 기본 실행 이름은 `ray_motion_no_roll_v2`다.
- no-roll 검증 데이터의 첫 20클립에서 최대 4윈도우씩, **80개 개발 샘플**로 nominal anchor를 비교했다. 수정 전 **61.085mm**, 수정 후 **62.057mm**다. 약 0.972mm 악화했으므로 이번 수정이 전체 데이터 평균 정확도를 높였다고 주장할 수 없다. 이 샘플은 구현 점검에 사용했으며 독립 최종 test가 아니다. 기하 오류 재현 해소와 학습 후 성능 개선은 구분해야 한다.
- 기본 미학습/eval 모델, CPU 4스레드, 16프레임 워밍업 뒤 15프레임의 스트리밍 간이 측정은 평균 **32.54ms**다. 실제 카메라 전처리·통신은 제외했으며 Pi/CUDA 지연이나 지속적인 30Hz 동작을 보장하는 값이 아니다.
- CUDA mixed precision 및 실제 카메라 일반화는 검증하지 않았다. 잔차 임계값은 현재 명목 설치 오차와 보수적 관측 허용을 위한 설정이며 실측 검증이 필요하다.
